## 1. 本期目标与范围

PCNet 本期形成面向 ISIS 10 控制网处理的 C++ 核心库与 CLI，重点解决控制网编辑阶段没有考虑后续 JIGSAW 平差改正模型的问题。

本期范围：

- C1：模型感知的控制网质量评价；
- C2：质量保持抽稀、网络连接保护与 DOM 空间粗差剔除；
- C3：围绕 ISIS `ControlNet` 的匹配/轨迹结果互操作；首期只提供外部格式转换到 `ControlNet` 的扩展点；
- ISIS `ControlNet` 是首期唯一的内部标准数据模型和主输入/输出格式；
- C4 DEM 高程控制不在本期实现，作为后续外部模块集成内容。

不在本期范围：

- 不实现或重写 ISIS 相机模型、SPICE 或完整 bundle adjustment；
- 不实现 C4 的 DEM 渲染、桥接匹配、误差传播和高程控制算法；
- 不把 PCMatch v1 作为首期正式接口；未来可另行设计简单的 KEY 类观测格式并转换为 `ControlNet`；
- 不要求 PCNet 映射或传递 JIGSAW 的底层单位、类名、参数缩放和约束接口。

## 2. 已确认的误差模型语义

用户在控制网处理阶段选择一个全网统一的 `error_model`：

- `constant`：单张线阵影像内部的常值改正；
- `velocity`：常值 + 沿单张线阵影像采集时间的一阶变化项；
- `acceleration`：常值 + 一阶变化项 + 二阶变化项。

模型选择用于 PCNet 的控制网质量评价、可观测性分析和抽稀决策。一次运行全网只能选择一个模型，因为当前 JIGSAW 使用全网统一模型。

PCNet 的模型是控制网处理阶段自己的分析模型。后续 JIGSAW 由用户独立选择对应的平差模型；PCNet 不负责 JIGSAW 单位映射。两者通过模型语义和筛选后的 `ControlNet` 结果关联。

时间变量针对单张影像内部的实际采集过程，由传感器适配器根据观测所属探测器通道、扫描线和曝光区间映射得到。固定曝光传感器可退化为逐线时间；可变曝光、多通道或非均匀扫描传感器则保留每条观测的曝光起止时间或等价时间矩。LRO NAC 与 HRSC 只作为验证这种抽象的代表性样例。

## 3. 总体架构

采用“核心算法与 ISIS 类型解耦、通过适配层连接”的路线：

1. **核心数据与模型层**：定义轻量网络视图、影像/点/观测索引、状态、原因码、误差模型和报告结构，不依赖 ISIS 类型。
2. **质量评价层**：计算 ImageQuality、PairQuality、NetworkQuality，包括覆盖、空洞、连通性、模型设计秩、条件数和预测方差。
3. **网络优化层**：执行质量预筛选、空间分块、关键桥接保护、模型感知抽稀、约束修复和 DOM 粗差过滤。
4. **ISIS 适配与 CLI 层**：读写 ISIS `ControlNet`，映射 SerialNumber/ControlPoint/ControlMeasure/相机时间，并提供配置、日志和报告输出。

数据流：

```text
ISIS ControlNet
      ↓
ISIS 适配层
      ↓
PCNet 轻量网络视图
      ↓
模型感知质量评价
      ↓
抽稀 / 粗差过滤 / 约束修复
      ↓
编辑结果与质量报告
      ↓
ISIS ControlNet + CSV/JSON
```

C4 后续集成点放在 ISIS 适配层之后、网络优化结果写回之前，以外部模块/扩展接口接入。

## 4. 轻量控制网表示

ISIS `ControlMeasure` 包含大量 PCNet 算法不需要的信息。核心算法不复制完整 ISIS 对象，而使用紧凑的轻量网络视图。

### 4.1 基本记录

`ImageRecord`：

- `image_index`：连续整数索引；
- ISIS SerialNumber 或内部标识；
- `acquisition_group_id`：同一次多通道扫描的采集组标识；
- `channel_id`/`detector_id`：原子影像对应的 CCD 或探测器通道；
- `image_name`：只在独立索引表保存一次；
- 宽度、高度；
- 采集时间范围（覆盖该影像有效观测的曝光区间）；
- 可选传感器通道/探测器标识及其几何偏移；
- 扫描位置到曝光区间的映射元数据、时间来源和精度标志。

`PointRecord`：

- `point_index`；
- 点类型/控制状态；
- 观测起始位置与数量，或等价的连续区间；
- 可选地面/DEM 坐标与参考系信息。

`MeasureRecord`：

- `image_index`；
- `sample`、`line`，均为 `float64`；
- 可选 `detector_id`/`channel_id`；
- `TemporalSupport`：一个或多个带权时间段 `[(t_start, t_end, weight)]`，或等价的一阶/二阶时间矩；
- `quality_weight` 或协方差：独立表示匹配/观测质量，不与 `TemporalSupport.weight` 混用；
- 所属点通过索引或连续区间关联；
- `state_flags`；
- `reason_code`；
- 可选质量列。

### 4.2 字段宽度

首期直接使用 `float64` 存储坐标，不引入 `float32/float64` 切换。

默认整数宽度：

- 索引：`uint32`；超过约 42.9 亿时再启用 `uint64`；
- 状态标志：`uint8`；
- 原因码：`uint8` 或 `uint16`；
- 文件头声明字段类型和索引宽度。

数据布局优先采用 SoA/列式连续数组，减少结构体对齐浪费并支持分块 I/O。

### 4.3 状态与质量字段

状态与原因码必须保留，用于：

- 标识当前是否参与计算；
- 记录粗差、几何冲突、用户禁用等原因；
- 支持迭代处理、前后比较和审计；
- 决定写回 ISIS `ControlNet` 时的保留/禁用/删除行为。

质量字段不无条件复制 ISIS 全部字段，只保留算法实际使用且语义明确的列，例如匹配分数、协方差/标准差、残差和来源 ID。

文件采用**单一版本化格式 + 可选质量字段区**，可形成 `minimal` 与 `quality` 两种存储配置，但不产生两套不兼容格式。文件头声明启用的字段和单位；无质量值时不分配对应数组。

## 5. 模型配置契约（当前版）

当前确认的公共模型名称：

```yaml
error_model: constant  # constant | velocity | acceleration
time_basis: exposure_interval  # 观测曝光区间；固定曝光时可退化为 midpoint
```

需要继续确定：

- 行号到曝光区间的具体映射来源和精度；
- 时间箱数量是否因数据集规模或传感器类型调整；
- 传感器适配器的具体时间元数据映射。

时间处理契约：

- 优先使用传感器适配器提供的每个观测曝光起止时间；时间基准范围取该影像所有有效曝光区间的并集，归一化到 `[-1, 1]`；
- 时间归一化域使用当前评价单元的支持包络 `[min(t_start), max(t_end)]`；包络内部的空档保留为空，不压缩掉；单影像按影像包络归一化，采集组汇总时按采集组包络归一化；
- `velocity`/`acceleration` 的设计矩阵使用曝光区间的一阶、二阶时间矩：对曝光区间 `I` 使用 `mean_I(tau)` 和 `mean_I(tau^2)`，而不是无条件使用中点值；
- 首期模型信息分析对所有有效观测使用单位权重；`TemporalSupport.weight` 只用于时间积分和时间矩，不改变观测统计权重；协方差、匹配置信度和相机先验暂不进入首期信息矩阵；
- 首期代理设计矩阵为：`constant` 使用 `[1]`，`velocity` 使用 `[1,tau]`，`acceleration` 使用 `[1,tau,tau^2]`；真实 ISIS 相机参数偏导留作后续独立验证，不进入首期核心接口；
- 若只有曝光中点，使用 `exposure_midpoint` 模式并记录近似标志；若只有行号和影像起止时间，才允许线性插值，并记录 `time_degraded=true`；
- 无法建立传感器内部一致的时间基准时，`velocity`/`acceleration` 模型分析标记为不可用，不静默拼接不同通道或扫描段的局部时间轴。

传感器适配器至少提供 `ObservationTiming` 能力：给定原始观测标识，返回 `TemporalSupport`、扫描坐标、可选通道标识、时间来源、精度等级和降级标志。`TemporalSupport` 可以只有一个区间，也可以包含多个不连续或不同权重的时间段；核心算法只消费这一抽象，不依赖 NAC、HRSC 或其他具体传感器字段。

## 6. 质量输出（当前设计）

首期固定三类原始指标表，综合评分只作为可选排序辅助，不替代原始指标。

### ImageQuality

- 影像标识、模型名；
- 点数、观测数、邻接影像数；
- 沿轨时间覆盖为主指标：按归一化时间分箱统计覆盖率、最大时间空洞和有效时间跨度；
- 横向覆盖为独立指标：按归一化 sample 分箱统计扫描幅宽覆盖率和横向空洞；
- 二维 `8×8` 网格覆盖保留为辅助诊断，不作为线阵影像唯一覆盖判断；
- 起始/中部/终止段覆盖：按归一化时间 `[-1,-1/3)`、`[-1/3,1/3]`、`(1/3,1]` 三等分，分母为该影像有效观测或有效控制点总数；
- HULL 比率、时间跨度、最大时间空洞；
- 模型设计秩、条件数、最大预测方差；
- 警告和失败原因。

### PairQuality

- 影像对、有效连接点数、独立连接点数；
- 有效重叠区域：两张影像有效成像 footprint 在统一局部投影坐标系中的几何交集；若 footprint 不可用，则回退到有效观测点凸包交集，并设置 `overlap_fallback=true`；
- 沿轨时间覆盖、横向覆盖、沿轨/跨轨跨度和最大空洞；
- 有可靠 footprint 时，在局部地面投影中计算二维网格覆盖；无 footprint 时仅输出传感器坐标覆盖并标记降级；
- 立体几何分数、桥接关键度；
- 警告和失败原因。

### NetworkQuality

- 影像/点/观测规模；
- 连通分量数、桥边数、弱影像/弱像对；
- 点数分位数、覆盖摘要、模型信息摘要；
- 运行时间、峰值内存和 I/O；
- 配置、输入摘要、版本和可重复性哈希。

所有指标输出必须携带定义元数据：分母、有效区域、坐标/投影、网格尺度、无效值规则、时间规则和模型配置。

## 6.1 通用线阵/推扫影像覆盖指标契约

针对线阵、推扫、多通道或非均匀曝光传感器，覆盖评价采用传感器坐标与地面坐标分层计算，避免把采集时间、扫描方向和横向探测器位置当作同一种空间维度。NAC、HRSC 等现有传感器用于适配器和回归测试，不定义核心接口。

- **沿轨主指标**：将归一化曝光时间域 `tau ∈ [-1, 1]` 等分为 8 个时间箱，按有效曝光区间的并集与时间箱的重叠长度进行占用统计，同时报告有效独立点数；时间箱数量可配置并写入报告元数据。
- **横向独立指标**：将归一化 sample 范围等分为 8 个横向箱，统计非空箱比例、最大横向空洞和每箱有效独立点数。
- **起止段指标**：继续使用三段定义 `[-1,-1/3)`、`[-1/3,1/3]`、`(1/3,1]`，作为沿轨主指标的摘要。
- **二维传感器网格**：保留 `8×8` 网格作为辅助诊断；其空箱统计不能替代沿轨时间覆盖或横向覆盖。
- **地面二维网格**：仅当 ISIS 适配层能提供可靠 footprint 和统一局部投影时计算；网格以有效重叠区域为边界，并记录投影、网格尺寸和回退状态。
- **分母与稀疏性**：时间箱、横向箱和二维网格均使用各自有效域作为分母；时间箱优先使用曝光区间并集占用率，点数作为独立稀疏性辅助量；曝光时长加权覆盖作为辅助列，用于反映采集质量或运动模糊风险；样本不足时输出 `*_sparse` 标志，不把空箱直接解释为模型不可观测。
- **模型关联**：`constant` 主要依赖连通性与空间覆盖；`velocity` 必须检查沿轨时间跨度和时间箱分布；`acceleration` 还必须检查起始、中部、终止三段及最大时间空洞。

默认输出 CSV + JSON；GeoJSON/Parquet 作为后续扩展。

## 6.2 质量保持抽稀契约

抽稀采用两层决策：先筛除明确无效或重复观测，再在候选集中执行带硬约束的模型感知选择。

硬约束包括：网络连通分量不得增加；关键桥接点、唯一连接像对、用户保护点和检查点不得删除；每张影像的最低沿采集时间覆盖、横向覆盖和有效独立点数不得跌破配置阈值；选定误差模型的设计秩、条件数和最大预测方差不得恶化到不可用。

在满足硬约束的候选中，以模型信息增益为主目标，并联合考虑空间覆盖、时间覆盖、连接性、观测质量和冗余度。无法同时满足预算与硬约束时，停止抽稀并输出约束冲突原因、剩余规模和未满足指标。

抽稀预算同时支持 `max_control_points` 和 `max_measures`。前者作为主要规模预算，后者限制高连接点导致的观测规模；只设置一个时另一项不设上限，同时设置时必须同时满足。报告记录两个预算的输入值、触发状态以及输入/输出的 ControlPoint 和 ControlMeasure 数量。

## 6.3 DOM 空间粗差检测契约

PCNet 首期在平差前生成和编辑平差输入，不运行 bundle adjustment，也不把平差结果作为核心闭环。粗差检测先做局部相对几何一致性检验，再结合输入中已有的残差字段（若存在），最后将 DOM 坐标差异作为辅助证据。DOM 证据必须结合配准误差、地形坡度和高度不确定度解释，不能单独把二维偏移判为错配。

每次候选剔除记录 `reason_code`、检测阶段、阈值、残差或偏差值、迭代轮次和输入版本；过滤过程不得破坏网络连通性、保护点和模型可观测性。达到残差稳定、最大迭代次数或继续剔除会违反硬约束时停止，并输出未解决候选。

残差过滤支持两种输入模式：`residual_magnitude`/`sample_residual`/`line_residual` 已由外部平差或编辑流程写入时，允许按显式像素阈值过滤，例如 `residual_magnitude > 10 px`；没有可靠残差字段时，才使用局部几何和 MAD 鲁棒检验。残差来源、生成时间、单位、阈值和过滤结果必须写入报告；PCNet 不自行生成平差残差。

## 6.4 CLI 错误与输出契约

CLI 使用稳定错误码：`0` 表示成功，`10` 表示完成但有质量警告，`20` 表示输入/格式/配置错误，`30` 表示所选模型需要的传感器时间能力不可用，`40` 表示读写或资源错误，`50` 表示内部错误。抽稀预算与硬约束冲突时输出审计报告并标记 `constraint_unsatisfied`。

致命错误默认不写入部分编辑结果；质量警告允许输出结果但报告状态为 `warning`。编辑结果先写临时文件再原子替换。JSON 报告始终记录状态、错误码、输入摘要、配置、已完成阶段和未完成原因。

CLI 首期命令边界为：`pcnet inspect`（只读检查输入、规模和传感器时间能力）、`pcnet quality`（生成三级质量表）、`pcnet thin`（质量保持抽稀）、`pcnet filter`（DOM/几何粗差检测与禁用）和 `pcnet validate`（格式、连通性、时间模型及写回结果校验）。五个命令共享版本化配置；后续可增加显式的 `pcnet pipeline` 串联入口。

P0 只读核验必须生成可复现报告，记录 ISIS 环境版本、头文件/库/ABI/CMake 信息、ControlNet 最小读写往返、可用的 `ObservationTiming` 接口、JIGSAW 可核验事实、编译命令和失败原因。未核验的 API、单位或约束语义不得进入正式 SPEC。

测试数据分为三层：确定性合成小样例，用于验证时间矩、覆盖率、设计秩、条件数、抽稀约束和原因码；传感器适配器夹具，覆盖固定曝光、可变曝光、多通道和多段 `TemporalSupport`；真实数据子集，用于比较编辑前后控制网规模、连通性、覆盖、禁用记录和残差字段处理。独立检查点按空间、采集时间和影像连接分层抽取，并与抽稀目标、粗差检测和参数调优隔离。规模测试覆盖 100 万 ControlPoint，1000 万作为扩展压力测试。

## 7. 首期性能边界

- 100 万 `ControlPoint`：本期必须验收；
- 1000 万 `ControlPoint`：扩展压力测试目标，不作为首期功能完成条件；
- 性能报告至少记录 ControlPoint 数、ControlMeasure 数、运行时间、峰值内存和 I/O。

- 坐标使用 `float64`；
- 状态/原因码保留，质量列可选；
- 粗差处理默认采用可逆的观测禁用并保留原始记录、原因码和迭代证据；只有显式启用压缩写回时才物理删除已审计观测；
- 单一版本化格式、可选质量字段；
- 通用线阵覆盖以沿采集时间覆盖为主、横向扫描覆盖为独立指标，二维 `8×8` 网格仅作辅助诊断；
- 时间模型以观测曝光区间为基本单位，支持固定曝光、可变曝光、多通道和非均匀扫描传感器；
- 时间支持使用 `TemporalSupport` 表示，可包含多个带权时间段；按评价单元的时间包络归一化到 `[-1,1]`，内部空档保留；
- 时间积分权重与观测质量权重分离；
- 首期模型信息分析对有效观测使用单位权重，不引入协方差、匹配分数权重或相机先验；
- 首期模型信息分析采用 `[1]`/`[1,tau]`/`[1,tau,tau^2]` 最小代理设计矩阵，真实相机参数模型作为后续验证；
- PCNet 首期定位为平差输入生成与编辑工具，不运行 bundle adjustment；若输入已有外部残差字段，可按显式阈值进行可审计粗差过滤；
- ControlNet 保持原子影像语义，多通道通过 `acquisition_group_id` 关联，不强行合并为单个影像；
- PCNet 不映射 JIGSAW 底层单位和接口。
